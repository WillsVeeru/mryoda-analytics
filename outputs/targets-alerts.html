Targets & Alerts Formulas

Expected activity to date

Monthly target × elapsed calendar days ÷ calendar days in the selected month. Rounded once to a whole rupee or whole test, according to the selected metric. Past months use the complete month; future months have zero elapsed days. Current-month pace includes today in the Asia/Kolkata timezone.

Pace and achievement

Choose Revenue or Test count. Gap to pace = actual activity for the selected metric − expected activity to date. Negative means Behind pace, positive means Ahead of pace and zero means On pace. Achievement = actual activity ÷ the monthly target for the same metric × 100. When both target and actual are zero, achievement is 100%; a positive actual against a zero target has no finite achievement percentage.

Current and previous month targets

People remain visible even when no target has been saved. Previous target is the saved target for the immediately preceding calendar month, not the prior edited value. The existing demo team and six supplied PROs have clearly labelled sample targets and activity. New people use their saved target; missing actuals and differences display —, with Awaiting activity as the status. A saved zero target remains zero. Each month shows its own target, actual net revenue or test count, difference and status. Difference = that month’s actual activity − that month’s target for the selected metric. Previous-month actuals cover the complete previous month when it has ended; current-month actuals run through today. Negative is Shortfall, positive is Excess, and zero is Target met. No target set and Awaiting activity indicate missing inputs. Previous-month fields display — when no history is available. Saving a target preserves available current and previous activity. Confirmed zero activity displays 0 and is used in the difference calculation; missing activity is never treated as zero. Monthly results are provisional until month-end; pace alerts compare actuals with the expected target to date.

Targets set

Count of people with a current target matching the selected month and table filters, including sample targets when no saved target exists. Sample targets are preview values; they are not saved automatically. The same person may have targets under different scopes; their activity must not be summed across scopes. Revenue and Test count targets are stored independently and never added together.

Scopes and actuals

PRO uses the assigned PRO ID, Account Manager uses the account manager ID, and Sales Rep uses the sales representative ID. Actuals use the latest matching Financial Overview snapshot for the exact period, through the current day for this month. Test count actuals sum the available test counts assigned to the same person and scope. Missing test-count inputs remain unavailable rather than being inferred from revenue. Missing actuals for new or unmapped people remain unavailable. Only explicitly marked preview people use labelled sample activity. Available Financial Overview actuals take priority, including zero.

Provided PRO names

The 18 visible names and designations in the supplied dropdown are included. Source IDs and unseen entries were not supplied. REF-PRO keys are local target keys, not source PRO IDs; targets can be saved, while real actuals require source ID mapping. Six supplied PROs have labelled sample targets and activity for presentation; these are not source records. Other directory members have no generated activity or history. Saving a target leaves missing actuals as — with Awaiting activity. Existing demo people remain in a separate dropdown group to preserve saved targets.

Sample preview values

The existing demo team and six supplied PROs use stable, labelled sample values for each month. Other directory members never receive generated activity or history. Sample activity follows the elapsed part of the month. Saved targets and matching Financial Overview actuals take priority, including zero. Sample actuals stay fixed when a target is edited. Samples are never written to target storage or Financial Overview snapshots automatically. CSV exports identify the source of each value.

Saving and integration

Targets are stored in this browser, not on a shared server. Edited targets for existing dashboard PRO IDs continue to feed Financial Overview. Local-file navigation carries validated target state between pages. Account Manager and Sales Rep targets are stored separately from PRO targets. Both Revenue and Test count are stored per person, scope, metric and month. Saving a target does not create, clear or modify actual activity. Existing Financial Overview PRO revenue targets continue to use the revenue target only.
